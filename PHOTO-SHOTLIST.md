# Photo shot-list (replace the illustrated scenes with real photos)

Save photos into the `assets/` folder, then in `config.js` set for each gallery item:
`img: "assets/reception.jpg"` (leave "" to keep the illustrated scene).
Best size: 900 x 1100 px, JPG, under 300 KB each. Free sources: Unsplash, Pexels (check each licence).
